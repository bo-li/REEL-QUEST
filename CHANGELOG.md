# Changelog — REEL-QUEST

## [1.0.0] - 2026-10-30

First public release, accompanying the manuscript.

- **Database:** 169 ligands, 1,833 experimental conditions and 6,481 distribution
  ratios for the lanthanides plus Y and Sc (schema v0.3). Every condition cites the
  paper that measured it and the figure, table or text page the values come from,
  and was checked against that paper. Bounds (D > x, D < x) are stored as bounds and
  kept out of every fit, median and statistic; conditions measured with a
  co-extractant stay on the main ligand but out of everything pooled.
- **Classification:** a flat 21-subtype taxonomy by donor chemistry
  (`vocab/chemical_families.json`), mechanism labels, and per-ligand selectivity
  trends (Ascending, Reverse, Flat, Peaked, U_Shaped, Mixed, Insufficient_Data)
  with bootstrap confidence intervals on the slope.
- **Access:** Streamlit dashboard with an AI assistant; MCP server (ten read-only
  tools); Claude Code skill; read-only REST API; Python package; CLI.
- **Reproducibility:** every derived field recomputes from the stored measurements
  (`scripts/recompute_derived_fields.py --check`), every record validates against
  the JSON Schema, and the manuscript's numbers and figures are generated by
  `paper/stats.py` and `paper/figures.py`; CI runs all of it.
- **Contributions:** one file per paper under `contributions/`, checked on every
  pull request (`scripts/check_contribution.py`).
